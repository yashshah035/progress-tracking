Study rules

Weekday (60–90 min)

30 min course/video → 45 min coding by hand → 10 min writing notes in your own words.

Weekend (3–4 h)

Build the weekend project of your current phase. Projects are where real learning sticks.

Coding-agent rules

Phases 1–3: no agents for exercises (agents only to explain). After that: agents allowed, but you must explain every line they write. Use them as a tutor: "quiz me", "why this error?"

Phase 01 · Weeks 1–4

Rebuild Python & SQL

Goal: write Python & SQL without help

Why: everything else (ML, LLMs, APIs) sits on top of Python. If this is weak, everything feels hard.
Weekend projectA CLI expense tracker that saves data in SQLite (uses Python + SQL together).
📊

Phase 02 · Weeks 5–8

Data handling + math refresh

Goal: clean & explore data; understand math in plain words

Why: a data scientist's daily job is mostly data cleaning + exploration. Math intuition makes ML make sense instead of magic.
Weekend projectFull EDA notebook on a health dataset (e.g., UCI Heart Disease) — connects to your bio-medical domain.
🤖

Phase 03 · Weeks 9–14

Core Machine Learning

Goal: train, test & explain classic ML models yourself

Why: regression, classification, clustering, feature engineering, model evaluation — these are on your resume and in every ML interview.
Weekend projectClean → train → evaluate → save a model (joblib) on a public disease-prediction dataset. Like your phenotype work, but by hand.
🧠

Phase 04 · Weeks 15–20

Deep Learning + NLP

Goal: understand neural nets & fine-tune Transformers

Why: your resume says PyTorch, TensorFlow, Deep Learning, NLP, Computer Vision. This phase makes those true again.
Weekend projectFine-tune a small text classifier (e.g., DistilBERT) and run it locally — no agent writing it for you.
🚀

Phase 05 · Weeks 21–26

LLMs, RAG & Agents — your superpower

Goal: build & evaluate RAG/agent systems properly

Why: this is the hottest skill in the market AND your resume core (RAG, GraphRAG, LangChain, MCP, MiniRAG). This phase makes you dangerous here.
Weekend projectRebuild your Research Paper Chatbot from scratch, add RAGAS eval scores, write a great README. This becomes portfolio piece #1.
⚙️

Phase 06 · Weeks 27–32

Production engineering (MLOps lite)

Goal: ship code like a software engineer

Why: this is what separates "AI Engineer" from "notebook data scientist". Your resume already lists FastAPI, Docker, CI/CD, Redis — now own them deeply.
Weekend projectModel-serving service: FastAPI + Docker + pytest + GitHub Actions, deployed free (Render / AWS free tier). Portfolio piece #2.
💼

Phase 07 · Weeks 33–36

Portfolio, interviews, job push

Goal: show your work & pass interviews

End stateYou can say "I know Python, ML, LLMs/RAG, and I can ship to production" — and prove it with code. That is exactly what AI Engineer interviews test.
